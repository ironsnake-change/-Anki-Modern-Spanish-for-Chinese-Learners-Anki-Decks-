# 现西 Anki 牌组 · 使用说明

## 文件

- `01_现西词汇_全四册.apkg` — 3000 个词条 / 6000 张卡 / 4240 段发音
- `02_现西语法_要点与练习.apkg` — 48 条语法要点 + 30 道填空
- `03_现西动词变位.apkg` — 630 个动词 / 1260 张卡
- `现西词汇_源数据.json` — 全部字段，便于自行修改

## 导入

Anki 桌面版 → 文件 → 导入 → 选 .apkg，三个文件分别导入。

## 牌组结构

```
现西词汇            第 1–4 册，每册 16 课
现西语法            01 语法要点 / 02 语法填空练习 / 03 动词变位
```

## 卡片内容

**词汇卡**，每个词两张：

1. 西→中 认读：正面单词 + 发音；背面词性、中文释义、DLE 权威释义、例句、出处。
2. 中→西 产出：正面中文释义；背面拼写 + 发音 + 例句。

背面灰底的 **DLE** 行是西班牙皇家学院词典的原文释义（中译），用来交叉验证教材释义。

**变位卡**，每个动词两张：

1. 变位表：正面原形与释义，背面现在时六个形式。
2. 原形识别：正面原形，背面属于哪种变位、有无词根变化。

## 本版核对记录

用 **DLE 第 22 版完整电子版**（85863 词条，含词性、释义、全部屈折形式）作为主要依据，配合 RAE 在线接口与 Wiktionary 交叉验证。

逐条修订的问题包括：

- 释义错位：`mes`（更多地→月份）、`suplicar`（活着的→恳求）、`hermoso`（围困→美丽的）、`bien`（谢谢→好）
- 整列错行：第 1 册第 7 课"首都"页，多个国家名被配成首都名
- 整页乱码：`amenaza`、`torre`、`estructura` 等被识别成无意义字符
- OCR 残词：`ilevar`→`llevar`、`iavar`→`lavar`、`ilorar`→`llorar` 等 47 处
- 词性错误：`lengua` 动词→阴性名词、`calle` 感叹词→阴性名词等

结果：3000 条全部通过，词性覆盖 2987 条，DLE 释义 2045 条，例句 1492 条。

## 难度分级

先查通用词频表，查不到再用 44 万句西语语料补算，短语取最生僻的实词定级。高频 543 / 常用 533 / 进阶 1242 / 生僻 682。

## 学习节奏

大一阶段只开"西→中"认读卡，新卡每天 15–20 张。词汇量到两千左右再开"中→西"产出卡。变位卡建议跟着课文进度走，每课 5–8 个动词即可。

## 已知局限

- 137 条（多为专名、变位形式、短语）没有匹配到 DLE 释义，这些卡背面没有灰色对照行。
- 1508 个词条没有例句，主要是生僻词与专名。
- 语音为 TTS 合成，发音准确但语调机械。
- 变位表仅覆盖陈述式现在时。

## 数据来源

《现代西班牙语》学生用书 1–4 册；DLE（RAE，第 22 版）、RAE 在线词典、Wiktionary；语法参考《西班牙语基础语法与练习》（常福良）。
