## 安装

1. 安装 [Anki](https://apps.ankiweb.net/)（桌面版，Windows / macOS / Linux）。
2. 下载你需要的册数，双击 `.apkg` 文件即可导入。

按册拆分是为了文件体积可控，只需要哪一册就下哪一册。四册全部导入后，会合并成「现西词汇1」到「现西词汇4」四个顶层牌组，每册下面按课分开。

## 怎么用

**不要一次全开。** 3000 个词条对初学者是灾难性的量。建议：

1. 只导入当前在学的那一册，暂时只打开对应课的子牌组。
2. 在牌组选项里把「每天新卡上限」设为 **8–10 张**。
3. 这段时间只背「西→中 认读」方向，产出卡先留着。
4. 搜索框输入 `-难度::生僻` 可以排除专名和冷僻词。

第 1 课 51 个词，按每天 8 张算六天过完，一天十来分钟。第 1 册 878 个词约三个半月。可以续，比背得快更重要。

等词汇量到两千左右，再打开「中→西 产出」；变位牌组建议跟课文同步，每课 5–8 个动词。

## 卡片长什么样

**词汇卡**，每个词两张：

- 西→中 认读：正面单词 + 发音；背面词性、中文释义、DLE 权威释义、例句、教材出处。
- 中→西 产出：正面中文释义；背面拼写 + 发音 + 例句。

**变位卡**，每个动词两张：一张给现在时六个形式，一张考变位类别。

背面灰底的 **DLE** 行是西班牙皇家学院词典的原文释义（已译成中文），用来交叉验证教材释义。两者不一致时以 DLE 为准。

## 制作说明

词表来自教材扫描件的文字识别，中文释义由此产生，因此做了比较重的核对：

- 用 **DLE（Diccionario de la lengua española）第 22 版**离线全库（85863 词条）比对词性与释义
- 用 **RAE 在线词典**接口交叉验证
- 用 **Wiktionary**（kaikki 导出）补充词性与例句
- 逐条回查原页，修正了跨行错位、整列错行、整页乱码等多类识别错误

例句取自 Tatoeba 的西班牙语—中文对译语料与 Wiktionary 用例，都是真实语料，没有机器生造的句子。

## 已知局限

- 137 条词条（多为专名、短语）没有匹配到 DLE 释义。
